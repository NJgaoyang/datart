独立升级工具

报表配置升级

连接 Datart 数据库，检查并升级历史报表配置。保留业务数据、报表位置、账号和权限。

1. 连接数据库

请填写保存 Datart 报表配置的 MySQL 数据库，支持 MySQL 兼容的 MariaDB。

连接信息只在本次工具运行期间保存在内存中，不写入备份文件。

2. 检查与预览

连接并选择组织后，先检查需要升级的内容。检查不会修改数据库。

3. 备份与回滚

连接并选择组织后即可立即备份，无需先检查或升级。保存所选组织的全部仪表板、图表和组件配置，不修改数据库。

手动备份保存在工具所在服务器，仅保存配置，不是整库备份。升级时也会自动备份；在线回滚只适用于升级备份，如果配置后来又被编辑，工具会拒绝覆盖。

工具已就绪，尚未连接数据库。
只升级仪表板、图表和组件的配置，不处理数据视图字段元数据、数据库表结构或组织资源迁移包。历史模板文件仍可使用原命令行工具转换。
