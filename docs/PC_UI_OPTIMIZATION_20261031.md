# PC 数据集界面优化

分支：`dev20261031`。基于 `dev20261030` 已通过回归的 `82538430`。

## 范围

本轮优化数据集编辑的 PC 界面，沿用 Datart 主题、路由和组件体系。保留上一轮中文名称、字段身份、保存回显、关联表达式及导出逻辑。

## 操作变化

- 工具栏明确显示“执行”“保存”和保存状态；数据源可按名称搜索，预览行数有中文标签，详情设置与另存为收进“更多操作”。查询中显示真实的加载状态，避免把重新执行按钮显示为停止。
- 预览区增加标题、行列统计、空状态与加载说明，并提供“增大预览”和“恢复默认布局”。编辑区与结果区之间提供可见的拖动分隔线。
- 未选择数据集类型、创建关联视图时使用完整编辑空间，不保留空白预览面板。
- 右侧工具改为可聚焦的原生按钮，文字和图标一起显示。展开后的字段面板适配桌面可用宽度。
- 字段以中文主名、原名或来源次行展示。显示名编辑固定可见，其他操作收进更多菜单，长名称不挤占按钮空间。类型操作、显示名编辑、更多菜单支持键盘。
- 资源树搜索明确支持中文、英文名和注释；计算字段独立分组，模型内统一滚动。
- 数据集导航收起后通过明确的展开按钮恢复，不依赖鼠标悬停。折叠条使用当前主题颜色。
- 保存弹窗区分基本信息和高级设置，高级区收起后保留输入。关联配置区分来源与条件，字段有清楚的标签，窄编辑区可换行。
- 只读用户可以预览已有 SQL；SQL 编辑器、保存按钮及保存快捷键均遵守只读状态。既有后端权限检查保持。
