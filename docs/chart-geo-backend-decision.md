# Geo 图表后端决策门

## 决策：否

Task 15–19 的目标均可由 Datart 当前前端能力完成：已有中国省/市 GeoJSON、ECharts `geo`、`scatter`、`heatmap` 与 `lines` 已覆盖区域着色、气泡、符号、经纬度热力和流向展示。

本阶段不新增 GeoJSON 上传、区域资源存储、地图服务或后端 API。地图资源继续随前端静态发布，数据重组在前端完成；非法坐标和空节点在图表 option 生成时过滤。

只有出现“用户必须管理自定义区域资源”且静态 GeoJSON 无法满足的已确认需求时，才重新开启决策，并另行提交最小 API、存储模型、权限和迁移风险 RFC。
