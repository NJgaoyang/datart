# Datart 仪表板 UI 21 项分阶段优化 — 状态与验收

目标分支：`dev20261017`。本清单从源码修改和自动化检查角度跟踪，不将 UI 单测视为真实浏览器验收。

| 编号 | 项目 | 代码进度 | 仍需验收 |

## 可执行验证

在项目 `frontend` 目录：
```bash
npm ci --legacy-peer-deps
npm run check:grid
npm run build
npm run report:bundles
```

真实浏览器打开仪表板后，将 `frontend/scripts/dashboard-hit-target-audit.js` 粘贴到开发者工具的 **Sources → Snippets** 执行。分别在 1920 / 1366 / 1024 / 768 / 375 CSS 像素视口、不同浏览器缩放比例、侧栏收起/展开后运行。任何 `aligned=false` 均应视为潜在命中问题，并附截图与 DOM 标签信息。

注意：检查脚本只核对图标中心所在 DOM 命中目标，不会真实点击/保存；浏览器交互测试仍需人工或 Playwright 完成。
