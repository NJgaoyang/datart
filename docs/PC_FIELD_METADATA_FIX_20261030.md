# PC 字段中文与编辑流程修复

分支：`dev20261030`，基于 `dev20261028` 的 `1ff0f9b9`。

## 用户可见行为

- 首次保存数据集后接纳后台分配的字段 ID，继续修改中文名能正确持久化。
- 已有字段的显示名在弹窗确认后即时保存；字段树、候选列表和预览表同步更新，不把这次已保存的改名误标为整页未保存。原本未保存的 SQL、结构修改仍保留。
- 新 SQL 预览使用同一批字段元数据生成中文标签。
- 数据模型增加“更新字段注释”，使用已经同步的数据源注释，仅刷新当前已保存的数据集，保留人工名称及编辑器中的草稿。
- 新关联字段继承上游当前有效名称；已有人工名称或历史快照保持。明确清空后恢复当前来源名称。未修改的已保存关联 SQL 在预览无法解析嵌套来源时保留已确认名称；编辑后的 SQL、片段和已确认空注释不套用旧来源。
- SQL 资源树同时支持中文、原字段名、路径和注释搜索，并提供原字段名辅助信息。截断显示可查看完整文本。
- 计算字段在结构化多表数据集中保留完整来源路径，显示中文与保存的查询标识分别处理。
- 透视表按技术字段身份生成点击和联动数据，不用中文名称反查字段，不压缩未匹配列的序号。
- 后台明确清空的来源注释能清除已有图表中的旧注释；显式图表别名继续保留。
- Excel 展示名保留聚合含义，例如 `SUM(金额)` 与 `AVG(金额)`。
- 资源导出读取权威字段元数据，改名或清空后无需再整体保存即可正确导出。导入保留计算字段注释及明确的 null，不复活旧名称。
- 只读预览不提供字段类型或列权限编辑入口；高级设置的关联控件跟随实际表单值。
- 修改关联条件后必须重新生成 SQL，已过期的异步响应不会恢复旧的生成结果。
- 保存或查询期间切换标签页，失败信息和状态只回到发起操作的数据集；关闭原标签后不会影响其他标签。

## 兼容与范围

字段身份与展示文字继续分离。保留原有资源包 V1/V2 读取格式和数据库结构；导出副本中的一次性字段元数据在导入后移除，不成为额外运行时权威来源。

固定 Token 配置、用户登录方式、行权限、部署工作流没有调整。本分支的 CI 仅检查源码，不部署、不连接业务数据库。
